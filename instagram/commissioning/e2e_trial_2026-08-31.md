## Small blockers repaired during commissioning
1. **Registered validation workflow stopped before production-like batch generation.**
   - Added commissioning harness on isolated branch to run the existing generic `generate-batch` and review-index paths.
2. **Long two-line title clipping / Pillow bounding-box placement mismatch.**
   - Corrected glyph-bearing placement in `instagram/renderer/template_renderer.py` and added small layout tolerance.
   - Live batch improved from 10/11 to 11/11 successful items.
3. **Horizontal-bar renderer split labels inside words.**
   - Removed character-level split candidates; wrapping now uses word boundaries.
4. **Visual warnings were recorded but did not fail generic batch items.**
   - `generic_batch.py` now rejects items with visual warnings in the commissioning branch.
5. **Targeted regeneration did not enforce the same visual-warning rule.**
   - `generic_regeneration.py` now rejects regenerated items with visual warnings in the commissioning branch.
6. **Party project did not expose actual debate coverage.**
   - Added date-field detection and explicit period start/end to party records and visible output.
7. **Provenance existed only in metadata.**
   - Added visible chart footer with debate period and Oireachtas/Eirepolitic attribution.

## Larger blockers for follow-up
### A. Selected-item approval / ready-state architecture
`mark-ready` operates on the full source batch review state. Targeted regeneration copies the entire batch and does not narrow the review set to the selected item. As a result, the reviewed Fianna Fáil item cannot be marked ready without also reviewing the other ten party items.

Observed result: Fianna Fáil is approved, but `mark-ready` correctly returns failure because the remaining batch items are unreviewed.

Recommended follow-up: support a derived run or publication set whose run manifest and review state contain only selected items, or allow an explicit publication-selection manifest that the ready gate validates independently of the source batch.

### B. Caption/copy package is not native to the generic factory
The generic project/factory path has accessibility templates and visual metadata, but no native caption/copy-package stage was found. For this commissioning run, `caption.txt`, `alt_text.txt`, and `publication_package.json` were produced as a commissioning sidecar so the output is usable.

Recommended follow-up: add a generic editorial-package contract that produces caption, alt text, source note, method caveat, item/slide references, source batch ID, and review state as first-class factory artifacts.
